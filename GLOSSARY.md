# Dad's Toolbox

Free, ad-free, sign-up-free tools for everyday file and text tasks that people would otherwise do on sketchy websites. Everything runs on the visitor's own device.

## Language

**Tool**:
One self-contained task a person can run, such as turning an mp4 into a gif or making a QR code.
_Avoid_: Utility, script, app, convertor

**Site**:
The hosted website where anyone can use Tools in their browser and download the result, with no install or sign-up.
_Avoid_: Web app, frontend, platform

**Category**:
A group of related Tools, such as video converters or encoders.
_Avoid_: Family, section, module

**Converter**:
A Tool that turns a file from one format into another. A description of what a Tool does, not a separate kind of thing.
_Avoid_: Convertor

**Batch**:
The results from one press of a Tool's start button. Earlier Batches stay on the page when a person changes the options and runs the Tool again.
_Avoid_: Run, job, session

**Promise**:
What the Site guarantees every visitor: no name, email or account asked for, no ads, no trackers or visitor counters, and a person's files are never kept or sent anywhere. The one thing a Tool may hold is what a person chooses to Keep (Run Python's Program), in their own browser only, and it is never sent anywhere.
_Avoid_: Privacy policy, guarantee

**Style**:
How a QR code looks: its colours, its background or none, its dot shape and its corner shape (square, rounded or round; the corner shape is for the three big corner squares only). Whether it is saved as PNG or SVG is part of it too, and so is a logo in the middle, on a small patch of the background colour. Without a Style, a code is black on white with square dots and corners and no logo.
_Avoid_: Theme, design, skin

**Practice Tool**:
A Tool where a person practises a skill on the page, such as the Typing test or Run Python. It has no files to choose and no results to save. It keeps nothing, except that Run Python lets a person Keep their Program. Practice Tools sit in the Practice Category.
_Avoid_: Game, trainer, exercise

**Layout**:
Which letter each key of a keyboard types, such as QWERTY, Colemak or Dvorak. The Typing test's Layout option lets a person practise a Layout their computer isn't set to.
_Avoid_: Keymap, keyboard setting

**Lesson**:
One step of Vim practice: a set of Vim motions to learn, which also allows the motions of the Lessons before it. The last Lesson, Mixed, adds none and allows every motion.
_Avoid_: Level, chapter, unit

**Drill**:
One go at a Lesson: a short block of text, a cursor and a highlighted target to move the cursor to. A round is 10 Drills.
_Avoid_: Puzzle, challenge, task

**Signature**:
A person's name as they sign it, drawn with a finger or mouse or typed in a handwriting-style font (whichever way was chosen last), for Sign a PDF to put on a PDF's pages in black or blue ink. It is a picture of a signature, not a digital ID, and it is never kept: it is made afresh on each visit.
_Avoid_: E-signature, digital signature, autograph

**Mark**:
Something Sign a PDF puts on one page of a PDF: a Signature, or a short line of words (Text, such as a printed name; Today's date is a Text Mark filled with the device's short date), each with its own place and size on that page. A page can hold any number of Marks. A PDF's own form fields are not Marks.
_Avoid_: Stamp, annotation, field, item

**Program**:
The Python a person writes, or chooses from a `.py` file, in Run Python's editor. A starter Program is there the first time. A Program only runs when the person presses Run.
_Avoid_: Script, Code, Project

**Console**:
The part of Run Python's page where a Program's output appears as it happens, and where a Program that asks for typing waits for the person to answer. Python's own error messages appear there too.
_Avoid_: Terminal, Output window, Shell

**Keep**:
A person's choice, on Run Python, to have their browser hold their Program on their own device between visits. It is off by default ("Never keep") and can be changed at any time; turning it off deletes what was kept. What is kept is never sent anywhere.
_Avoid_: Save (saving writes a file), Remember, Store, Sync
