# Dad's Toolbox

Free, ad-free, sign-up-free tools for everyday file and text tasks that people would otherwise do on sketchy websites. Everything runs on the visitor's own device.

## Language

**Tool**:
One self-contained task a person can run, such as turning an mp4 into a gif or making a QR code.
_Avoid_: Utility, script, app, convertor

**Site**:
The hosted website where anyone can use Tools in their browser and download the result, with no install or sign-up.
_Avoid_: Web app, frontend, platform

**Category**:
A group of related Tools, such as video converters or encoders.
_Avoid_: Family, section, module

**Converter**:
A Tool that turns a file from one format into another. A description of what a Tool does, not a separate kind of thing.
_Avoid_: Convertor

**Batch**:
The results from one press of a Tool's start button. Earlier Batches stay on the page when a person changes the options and runs the Tool again.
_Avoid_: Run, job, session

**Promise**:
What the Site guarantees every visitor: no name, email or account asked for, no ads, no trackers or visitor counters, and a person's files are never kept or sent anywhere.
_Avoid_: Privacy policy, guarantee

**Style**:
How a QR code looks: its colours and its background or none. Dot and corner shapes (#74), the save type (#75) and a logo in the middle (#76) are planned. Without a Style, a code is black on white.
_Avoid_: Theme, design, skin
